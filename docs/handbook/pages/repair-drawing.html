Repair Drawing

Three repair passes in one dialog, run in the order that matters. rep

When you reach for it

An old drawing that predates a change; a drawing edited in another program; callout arrows that have come adrift; a cave whose layers look nothing like the palette.

The three passes

  1. Survey data first — re-derive the survey model from what the drawing already holds, and upgrade a legacy drawing's tags to the current schema. First because a legacy drawing's tags have to be current before anything else reads them.
  2. Layers second — add the registry layers this drawing is missing and rewrite colour, linetype and lineweight on the ones it has. A drawing keeps the layer appearance it was born with, so a cave started before a palette change stays on the old one until this runs. Second because rebuilding survey data can add layers.
  3. Callouts last — put every callout arrow back on its note after the note has been moved or reworded, and re-key a copied callout sharing an id with the original. Last because restyling can move a note onto a different layer and strand its arrows.

Each is a checkbox, on by default. One combined report; unticking a pass gives a line saying it was skipped.
