Caves

The window CaveCAD opens on: every cave registered on this machine, and what has been surveyed in it. caves

When you reach for it

At the start of a session. It is the door into an existing cave, and the way a survey file from someone else becomes a cave project.

Steps

  1. Pick a cave in the left rail. Its trips appear with date, team, shot count and the stations each one stopped at.
  2. Read the health line: depth, stations, loops, UIS grade, and warnings worth acting on — a bad loop closure, a declination IGRF disagrees with, unbound linework.
  3. Open drawing, or start a trip tied into an open end, or package the project, or open its folder on disk.
  4. Import Cave... reads a Compass, Survex, Walls or CSV file and builds the whole project from it — folder, scans/, PDF/, images/, backup/, and a drawing on the NSS template with the survey already drawn. Import Folder... takes a cave folder, or a folder of them.

Try it on Truitt

Open the shelf and read Truitt's trip table top to bottom. Every trip is a real day underground; the stations named in the last column are where the cave is still going.

When it refuses

  • A cave whose map is a DWG is listed with a convert badge rather than opened — CaveCAD reads DXF.
  • A teammate's new cave does not appear until it is added: registration is manual, deliberately, so nothing scans your Drive.
