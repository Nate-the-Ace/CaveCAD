Annotative text: one note, every scale

A note that reads right at 1" = 10 ft is a smudge at 1" = 100 ft. Annotative text fixes that the way AutoCAD does: the text has a paper height (say 0.1 inch), so it prints the same size whatever the scale of the viewport it appears in, and a list of scales it supports, each with its own position, so a label can sit in a different place on a sheet at each scale.

Making it

Everything is in the Annotation section of the Property Editor, as in AutoCAD.

  1. Select some text and tick Annotative. It starts with one scale, the current annotation scale (1" = 1' to begin with). Its present height is read as the paper height at that scale. Untick it to make the text ordinary again, as it looks at the current scale.
  2. Open the Scales menu next to the check box. Every scale is listed, all the imperial ones first, then the metric ones, with a tick on the ones the text supports. Pick a scale to add it or take it off (a text keeps at least one). A new scale starts where the nearest existing one has the text; change the annotation scale below and move the text at that scale, and only that scale's position moves.
  3. The second row of the section is the annotation scale itself and the All scales switch.

What you see

  • In the model, annotative text is drawn at the current annotation scale. At a scale it does not have, it is not drawn.
  • Press All scales in the Annotation section and the text's other scales appear too, shaded back, each at its own size and place; the current one stays normal.
  • In a viewport, text follows that viewport's own scale automatically, so there is no second setting to keep in step. A viewport at a scale the text lacks does not show it.

Good to know

  • Resize annotative text and you change its paper height for every scale.
  • Undo puts a scale's position back even if you have changed the annotation scale since (until you close the drawing).
  • Text only for now; blocks come next.
