Annotative text: one note, every scale

A note that reads right at 1" = 10 ft is a smudge at 1" = 100 ft. Annotative text fixes that the way AutoCAD does: the text has a paper height (say 0.1 inch), so it prints the same size whatever the scale of the viewport it appears in, and a list of scales it supports, each with its own position, so a label can sit in a different place on a sheet at each scale.

Making it

  1. Select some text and choose Annotate > Make Annotative. It starts with one scale, the annotation scale shown at the right of the strip above the drawing (1" = 1' to begin with). Its present height is read as the paper height at that scale.
  2. Change the annotation scale in the strip, select the text and choose Annotate > Add Current Scale. The new scale starts where the nearest existing one has the text; move it where you want it at this scale and only this scale's position moves.
  3. Delete Current Scale takes a scale off (a text keeps at least one). Make Not Annotative turns it back into ordinary text as it looks at the current scale.

What you see

  • In the model, annotative text is drawn at the current annotation scale. At a scale it does not have, it is not drawn.
  • Press All scales in the strip and the text's other scales appear too, shaded back, each at its own size and place; the current one stays normal.
  • In a viewport, text follows that viewport's own scale automatically, so there is no second setting to keep in step. A viewport at a scale the text lacks does not show it.

Good to know

  • Resize annotative text and you change its paper height for every scale.
  • Undo puts a scale's position back even if you have changed the annotation scale since (until you close the drawing).
  • Text only for now; blocks come next.
