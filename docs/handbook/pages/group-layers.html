Group Layers

File this drawing's layers into starter groups for the Layer Manager palette. gl

When you reach for it

Once, soon after a drawing exists, and again whenever a trip has added layers you want filed. A cave carries over 150 layers before per-run variants multiply them, and a fresh drawing opens with every one of them in a single Ungrouped heap. This makes the first arrangement so the palette is worth opening.

Steps

  1. Cave Survey > Group Layers.
  2. Open the Layer Manager (View > Layer Manager) to see the six groups.
  3. Rearrange them however you like. Right-click a layer for Add to Group, a group row for Rename or Delete.

The six groups

  • Plan, Profile, Sections — hand-traced ink, split by view.
  • Survey control — everything generated: shots, stations, LRUD, closure arrows, in all three views at once. Turning the survey skeleton off is one decision, not three.
  • Scans & basemap — sketch scans and the aerial imagery. Off together for a plot, on together for tracing, and the heaviest things on the screen.
  • Sheet — border, title block, scale bar, north arrow, and layer 0.

Notes get no group of their own on purpose: PROFILE-NOTES-DIG belongs with the profile you are working on, not in a pile of notes from three different views. Per-run variants land with their base layer for free — PROFILE-CEILING-A is profile, CTRL-SCAN-A is a scan — because a variant's token goes last and its prefix still reads.

It only ever adds

Run it again after a trip and it picks up the layers that have appeared since. Every group you made by hand, and every layer you filed by hand, stays exactly where it is. There is no reset to defaults, because the groups are yours the moment it has run once.

The groups live in the drawing, so they travel with the file, and everything about them is editable in the palette afterwards. This tool writes the first arrangement; it does not own it.

When it refuses

  • On a sheet. A sheet is rebuilt from the cave's record every time Sheet Setup runs, so anything written into one is lost. Open the cave's own drawing instead.
  • Without the Layer Manager. The groups are stored by that palette, so a build without it has nowhere to put them, and the tool says so rather than failing quietly.
